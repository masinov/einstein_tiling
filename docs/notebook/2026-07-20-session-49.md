# Session 49 — contracted parent-interface no-go

**Date:** 2026-07-20  
**Decision:** D-0057  
**Input:** the 17 generated and nine non-generated complete parent-corona
signatures from session 48.

## Experiment

For every directed parent edge, enumerate all neighbor states containing the
reciprocal edge. Around each central parent, assign one state to each of its
six neighbors and require pairwise triangle agreement: for any pair of those
neighbors, both assigned coronas must agree on whether the pair is adjacent.
Iterate deletion of states having no locally supported assignment.

This is the complete overlap language visible from uncolored radius-one
parent-anchor coronas. It deliberately does not invent full/missing labels or
physical interface colors that the state does not contain.

## Result

All 17 generated and all nine extra states have reciprocal domains on every
edge and at least two triangle-consistent assignments. Fixed-point support
pruning removes no state:

```text
states in       26
pruning rounds   0
states out      26
extra states out 9
```

Thus an uncolored parent-corona graph cannot prove contraction closure. This
is a finite no-go theorem for that abstraction, not evidence that the extra
states reach a whole-plane tiling.

## Next state refinement

Decorate every parent anchor with:

1. full versus missing component type;
2. the physical child-edge interval realizing each parent-parent contact;
3. orientation of that interface in the parent frame.

Extract the decorated states from the already enumerated radius-seven
physical witnesses and generated controls. Then repeat reciprocal, triangle,
and strongly-connected-component pruning. This retains precisely the data
that the uncolored experiment proved necessary.
