# Historical research record

The repository preserves its chronological research trace at stable paths:

- [`../STATUS.md`](../STATUS.md) — cumulative historical status narrative;
- [`../DECISIONS.md`](../DECISIONS.md) — append-only research decisions;
- [`../EXPERIMENTS.md`](../EXPERIMENTS.md) — historical experiment register;
- [`../HUMAN_CHECKPOINTS.json`](../HUMAN_CHECKPOINTS.json) — retired checkpoint
  registry;
- [`../notebook/`](../notebook/README.md) — numbered session records and their
  evidence assets;
- [`../program/`](../program/README.md) — superseded program specifications and
  controlling errata; and
- [`../archive/`](../archive/README.md) — frozen derivations and source notes.

These files are indispensable provenance, but none selects current work. Use
[`../research/status.md`](../research/status.md) for the present state and
[`../README.md`](../README.md) for the authority chain.

The files remain at their original paths so old citations, hashes, and audit
trails stay valid. This index supplies the missing semantic boundary without
rewriting two hundred chronological records.
