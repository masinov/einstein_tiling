# Session 52 — pinned radius-two parent-state CSP

**Date:** 2026-07-20  
**Decision:** D-0060

## Question

Can any of the three non-generated two-sided parent states terminate inside a
radius-two colored parent patch whose second ring is entirely generated?

## CSP

For each extra root, enumerate all triangle-consistent first stars: 28, 100
and 3. The first star fixes the root and its six neighbors. Add every anchor
named by those six complete coronas, producing 19–27 represented parent
positions. Assign one of the 20 two-sided states to each new position and
enforce:

1. exact reciprocal full/missing endpoint types and child-edge contacts;
2. agreement on adjacency or nonadjacency for every represented anchor pair;
3. exact nonoverlap of all physical children in the canonical 8/9 supports.

The objective first minimizes extra states on ring two, then minimizes extras
on all nonroot positions.

## Result

Only one first star per root extends. Thus 128 of 131 base CSPs are UNSAT.
The three surviving problems were exhaustively enumerated:

| root | models | min outer extras | min nonroot extras | forced outer type |
|---|---:|---:|---:|---|
| `288091b49587a4b2` | 960 | 1 | 3 | `2f1d7f0fac5b9704` |
| `2fb5d0cf9a68ffe2` | 432 | 1 | 2 | `2f1d7f0fac5b9704` |
| `2f1d7f0fac5b9704` | 840 | 1 | 3 | `288091b49587a4b2` |

An independent CaDiCaL encoding replayed all 131 base problems and all 131
variants forbidding outer extras. It reproduces 3 SAT / 128 UNSAT for the
base problems and UNSAT for every generated-only outer ring.

The formerly radius-one-absorbable state therefore feeds into a mutually
propagating pair. This is not yet an unboundedness theorem: repeated local
implications could revisit an earlier anchor and form a finite cycle. It is
not a contradiction and does not prove such configurations exist.

## Next experiment

Continue the unique surviving first-star branches to parent radius three.
Test whether the forced `A/C` relation dies geometrically, closes into a cycle
or fault line, or admits a density/discharging invariant incompatible with a
full parent packing.
