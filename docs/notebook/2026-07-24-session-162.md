### Outcome decisions

- `sat` reopens the named carrier cell only if every reported value is
  rational or structurally recognized in `Q(sqrt(2))` and an independent cold
  verifier reconstructs `t_0`, checks `Delta=0`, then verifies the original
  K34Q geometry and all 120 nonintersection predicates.
- A `sat` model containing any unsupported algebraic value, or one failing
  cold verification, is preserved but leaves the cell open.  It does not
  authorize approximation, fitting or a second solver call.
- Bare `unsat` is recorded as cvc5/CAC evidence only and does not close a cell

- `unknown`, external resource stop, killed process, malformed output or
  launcher failure leaves the named cell open.  None authorizes retry,
  alternate options, another solver or a larger budget.
