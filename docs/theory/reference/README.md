# Theory reference and provenance

- [Result catalog](result_catalog.md) is the compact theorem/application
  index used for navigation.
- [Proof ledger](proof_ledger.md) is the complete row-level record of IDs,
  scopes, statuses, dependencies and certificates.
- [Source map](SOURCE_MAP.json) is the machine-readable coverage map from all
  former numbered notes to canonical documents and preserved proof sources.

The catalog is curated; the ledger is exhaustive.  A statement absent from
the catalog may still be valid at a narrow scope recorded in the ledger.
