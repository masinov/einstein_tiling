# Session 58 — 2026-07-21 — Kaplan eight-kite coordinate crosswalk

## Experiment pre-registration

### Proposition

Kaplan's 116-page `8kites.pdf` artifact and this repository's complete
eight-kite classifications represent the same 116 individual shapes, not only
the same aggregate counts: 108 with `H_c=1`, five with `H_c=2`, two periodic
anisohedral tilers, and the Hat.

### Prior art and non-redundancy

The controlling sources are Kaplan's peer-reviewed Heesch definition, public
`heesch-sat` kite-grid implementation at commit
`1adb37204013b96b62b954a616265e49d7cf21ad`, the official 2023 PDF and comments,
and the Hat paper's `n<=24` classification. The PDF publishes coordinates and
classifications, so the mathematical data are known. No coordinate-level map
to this repository's `(u,v,s)` canonical keys was located. The only intended
contribution is a reproducible cross-implementation benchmark bijection.

### Outcome decisions

- A 116/116 unique bijection permits the benchmark to claim per-shape
  reproduction and records the exact coordinate conversion; no wider census
  is authorized.
- Any missing, duplicate, or classification-disagreeing shape blocks the
  per-shape claim and is reported as a semantic/coordinate discrepancy; it
  does not authorize another radius, size, or solver campaign.

### Stop rule and finite justification

Parse each of the fixed 116 PDF pages once, derive the coordinate conversion
from Kaplan's public `kitegrid.h`, and compare canonical identities against the
existing database. Stop after one complete pass, after ten minutes of
coordinate-conversion investigation without a derivation, or before producing
10 MB of new artifacts. This finite task closes a benchmark identity question;
neither outcome calls for a larger search.

### Human checkpoint

Checkpoint `HC-2026-07-21-01` covers through session 57. This is research
session +1 of the permitted three, and the planned output is a small mapping
summary far below the 1 GiB artifact allowance.

## Results

The exact conversion follows directly from Kaplan's `KiteGrid` representation.
For one of his cell points `p`, there is a unique direction `d` for which
`p-origin[d]` is a legal hex center; the repository cell is
`(p-origin[d], d)`. Applying this conversion to all eight points on every PDF
page and then using the production D6 canonicalizer gives 116 distinct keys,
all present among the repository's 873 free eight-kites.

The individual classification crosswalk is exact:

| class | matched shapes |
|---|---:|
| `H_c=1` | 108 |
| `H_c=2` | 5 |
| periodic anisohedral | 2 |
| Hat | 1 |

Kaplan's three inconclusive pages map to repository shapes `506` and `793`
(periodic anisohedral) and `635` (Hat), on PDF pages 32, 47 and 50
respectively.

```text
venv/bin/python scripts/run_research.py docs/notebook/2026-07-21-session-58.md -- venv/bin/python scripts/run_kaplan_8kite_crosswalk.py
```

It pinned the source PDF SHA-256, parsed exactly 116 three-line pages, required

compared the latest A1/A2 verdict and exact `H_c` depth per shape. Artifact:
`docs/notebook/assets/kaplan-8kite-crosswalk.json` (34,828 bytes).

The first pass exposed a representation-only bug in the runner: `HAT_KEY` is
the compiled fixed-width key, while PDF records had already been converted to
database serialization. Decoding `HAT_KEY` before serialization corrected the
comparison; no search parameter or result was changed.

## Decision

The per-shape benchmark identity is closed: this repository independently
reproduces Kaplan's public eight-kite `H_c` classifications shape by shape.
This authorizes a stronger reproduction claim, not a novelty or wider-census
claim. No follow-up computation is required.
