# Foundations

This layer contains source-independent tiling dynamics needed by every later
construction or obstruction.

- [Periodic completion](periodic_completion.md): grid-aligned finite tiles
  form a two-dimensional SFT; one nonzero period can be completed to a
  rank-two period lattice.

Local-factor period descent and finite quotient safety are integrated with
the realization results in
[general theory](../realization/general_theory.md), where totality is the
load-bearing hypothesis.
