## Minimal-core theorem

The Hall matcher now deletion-minimizes every deficient subset before affine
analysis. For any inclusion-minimal four-center Hall core `S`, elementary
counting proves and executable checks enforce:

- the tile-intersection graph is connected;
- `delta = 2|S|-|N(S)|` is 1 or 2;
- every tile has at most `2-delta` private centers;
- `sum_j (j-2)n_j = 2 delta` for the center-degree counts `n_j`.

This is T2.D7-H0. Tests include both possible deficiencies and an irrelevant
component that the minimizer must remove.

answer. Under the original one-orbit packing relaxation, source 11 lifts to a
75-tile/149-center V4-compatible Hall core. It avoids the T2.D6 six-kite orbit
but contains seven translates of one different four-kite overlap.

Strengthening the source master to **full nonoverlap** does not repair Hall.
Its first source lifts to a deletion-minimal finite set with:

```text

distinct centers = 125
required matching capacity = 126
deficiency = 1
center degrees: n_1=18, n_2=87, n_3=20
actual overlapping pairs = 0

```

The cold verifier checks the literal list rather than trusting the discovery
solver: exact Hall witness and deletion minimality, exact cellwise
nonintersection, no quotient seam in any selected equation, XOR compatibility,
and a separate CaDiCaL implication replay. Result: **PASS**.

Therefore T2.D7-H is refuted even under full packing. Small 2x2--4x4 windows
were boundary controls, not evidence of an all-window theorem; the periodic
lift correctly found the first larger obstruction. This does not produce a
tiling or refute aperiodicity. It only retires this density proof architecture.
