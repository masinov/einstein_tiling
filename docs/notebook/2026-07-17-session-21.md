# Session 21 — independently verified W1 negatives and finalist norm theorem

**Date:** 2026-07-17  
**Scope:** close W1's negative-certificate gap and apply it to the first exact
bounded-norm finalist classification.

## Negative certificate format

The W1 producer now emits a complete `cylinder-cycle-free-certificate`, not
only a graph hash. It contains exact placement patterns, crossing
contributions, every enumerated state and transition, transition placement
witnesses, and a complete topological ordering.

The independent verifier in `src/einstein/theory/transfer_verify.py` recompiles
the cylinder geometry and re-enumerates states and transition targets without
calling the producer's graph routines. Tests reject a removed state, removed
edge, invalid ordering and any attempt to certify a cyclic instance.

Five complete control certificates pass independently: the Myers-validated
two-kite non-tiler and the hat at vectors `(1,0)`, `(0,1)`, `(1,1)` and `(2,0)`.
Together they contain 85 states and 40 edges. Artifact:
[`theory-w1-cycle-free-controls.json`](assets/theory-w1-cycle-free-controls.json).

## Finalist bounded-norm run

The exact (D_6) action was used to enumerate every nonzero center-lattice
vector with (Q(x,y)=x^2+xy+y^2\le25), without dropping nonprimitive vectors.
There are 90 vectors in 11 orbits. Every representative produced a complete
cycle-free graph and every certificate passed the independent verifier:

**Machine-verified conclusion:** no grid-aligned finalist tiling has a nonzero
translation period (v) with (Q(v)\le25). There were zero cycles and zero
resource exhaustions. Artifact:
[`theory-w1-finalist-norm25.json`](assets/theory-w1-finalist-norm25.json).

This is the first bounded-vector theorem for the finalist. It is stronger in
logical kind than finite torus-index sweeps, because it decides existence of a
tiling with each specified period irrespective of the second period. It is not
universal aperiodicity: all vectors beyond the norm bound remain open, and the
scope is grid-aligned.
