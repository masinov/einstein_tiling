# Historical research programs and errata

The two program documents in this directory are historical planning sources:

- `einstein_search_program.md` is the original broad search proposal;
- `theory_research_plan.md` is the former Turtle-control workstream plan.

Neither is current theory navigation or authorization. Their corrections
remain append-only in `ERRATA.md`. Current mathematics starts at
[`docs/theory/README.md`](../theory/README.md); maintenance policy starts at
[`docs/consolidation/README.md`](../consolidation/README.md).

Statements inside the preserved program documents describing either document
as "living", "current", or an authorization source are historical statements
from the time of writing. They are superseded by
[`docs/README.md`](../README.md) and the current
[`research charter`](../research/charter.md).
