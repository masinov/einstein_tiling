## Recursive probe

The forced 315-anchor parent patch does not obey the Spectre simplification:
no single full-plus-one-deletion rule among exact nearest clusters of sizes
6–12 covers even the next safe core. Allowing arbitrary nearest 7/8 groups
does cover, but attempts to make the selected root/group size a deterministic
function of radius-1 through radius-4 geometry-only collar state are UNSAT.
The next solver must therefore mine a genuinely multi-type rule jointly with
the unresolved full/A/B assignment; freezing an arbitrary ownership cover
throws away required state.
