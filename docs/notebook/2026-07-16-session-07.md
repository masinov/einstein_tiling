## Failures and corrections

1. The first exploratory claim that exact cover selected a unique rule was too
   strong. Two phase-shifted deletion hypotheses each give a unique cover and
   survive a larger Delta patch plus all nine root labels.
2. A first hidden-validation comparison used row numbers. The two Rust
   traversals have different enumeration order, producing a false 0% score.
   Joining by exact `(s,r,t0..t3)` pose fixes the trust boundary.
3. Frequency of the 8-tile neighborhood selects the wrong phase. Exact
   adjacency cohesion distinguishes them: the correct exception has 34
   internal / 44 exposed edges versus 32 / 48 for the alternate phase.
4. Many internal adjacent-pair motifs can be fused algebraically. Therefore
   this session does **not** claim blind recovery of the hidden two-tile Gamma
   child or the nominal eight-child rule merely from the 9/8 physical counts.
