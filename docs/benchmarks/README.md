# Reproducible benchmark records

This directory separates classified-corpus evaluation from discovery claims.
A benchmark here must identify its frozen corpus, concealed labels, protocol
commit, comparison methods, metrics, unknown outcomes and leakage audit.

The first assessment is
[`E1_CLASSIFIED_CORPUS_ASSESSMENT.md`](E1_CLASSIFIED_CORPUS_ASSESSMENT.md).
It concludes that the existing E1 history is a valuable validation/postmortem
but not a clean quantitative discovery benchmark. No replay is authorized by
that conclusion.
