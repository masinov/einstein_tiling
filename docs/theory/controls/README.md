# Exact controls on published tilings

These documents exercise general certificate machinery on known systems.
They may contain valid finite theorems and reusable algorithms, but their
tile-specific conclusions are controls rather than discovery claims.

- [Turtle controls](turtle/README.md): transfer graphs, quotient incidence,
  finite-group holonomy and certified finite torus exclusions.
- [Spectre controls](spectre/README.md): finite physical languages, parent
  transducers, contraction closure and the unrestricted edge-contact bridge.

The published aperiodicity proofs remain the authority for both tiles.
