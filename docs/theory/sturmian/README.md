# Exact Sturmian benchmark theory

[AHI source and carrier theory](ahi_source_and_carriers.md) integrates the
exact reconstruction of the Akiyama--Hamada--Ito Section 10.1 system with the
carrier-local composition, frequency, boundary and parity reductions derived
from it.

This is a precise benchmark, not a classification of all Sturmian sources.
The active source-independent question is stated in
[`../research/sturmian_realization.md`](../research/sturmian_realization.md).
