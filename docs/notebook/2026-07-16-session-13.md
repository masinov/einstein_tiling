## Exact semantics

For each shape, A1 tests every HNF sublattice of index k≤12 for which the
quotient's `6k` kite cells contain an integer number of shape copies.
Placements are deduplicated by exact `u128` torus masks, and exact cover
branches on the uncovered cell with the fewest compatible placements.

Only a found cover retires a shape. A refutation at the finite index budget and
a node-budget exhaustion both stay in the survivor stream. In this run no
search exhausted the 200,000-node per-HNF budget.

n=13 requires k divisible by 13 and therefore has no admissible k≤12; n=16
admits only k=8, corresponding to three tiles per fundamental domain.

## Performance

- n=14: 22.10 s, 16 workers.
- n=15: 364.90 s, 16 workers.
- n=16: 673.06 s, 16 workers.

Precomputing all twelve oriented lattice images once per shape and replacing
per-HNF placement hash tables with tiny linear mask sets reduced the n=16
sample cost by about 25%.
