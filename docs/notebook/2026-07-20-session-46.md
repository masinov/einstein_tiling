## Question

Can the recovered 17-state substitution language be validated without using
vendor ancestry by enumerating physical local patches and finding a finite
radius at which each viable central tile has a total, unique parent?

## Exact method

The experiment begins with only the exact 14-edge polygon in the rank-four
module. For every exposed directed edge it enumerates all rotated/translational
mates, rejects exact interior overlaps, and solves complete ring coverage with
CaDiCaL. The first-corona enumeration contains no substitution label, child
slot, parent path or generated-patch filter.

Generated level-3 and level-4 patches for all nine root labels form a separate
positive control. Recovered full/missing parent templates are applied only
after the bare physical language has been enumerated. Negative radius-three
decisions exhaust every radius-two completion; survivor decisions require one
exact witness. Targeted radius-four checks are existence probes for only the
three unobserved radius-three branches.

not a complete catalog of all radius-three patches. A finite witness is not a

domain obligation. The external Chéritat theorem proves the Spectre result;
