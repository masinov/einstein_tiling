the 32 even-parity words in `{0,1,2,3}^3`. Map each remaining state to a fresh
diagonal triple `(4+t,4+t,4+t)`.

states. Its image is non-Cartesian because all coordinate projections contain

compiler: independent side choices admit a spurious mixed star.

This does not prove that all safe distributed codes require corner coupling,
that both large types are essential, that `n=62`, or that four modes suffice
for the selected code.
