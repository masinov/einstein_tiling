## Exact filter

For each seed shape:

1. enumerate the exact vertex-adjacent empty ring;
2. generate every grid-congruent placement covering at least one ring cell
   and disjoint from the seed;
3. exact-cover the ring with pairwise disjoint placements;
4. reject complete covers whose union contains a bounded empty component.

If every branch fails, H_c=0 is exact. If a valid cover is found, the shape
survives with the placement list. If the node budget is exhausted, the shape
also survives and is written to a separate escalation stream.
