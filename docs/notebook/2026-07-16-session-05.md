## Calibration failures and corrections

1. Mixed anchor sets were dominated by substrate-lattice peaks, obscuring the
   aperiodic orientation densities. Switched all references to the same
   per-orientation-class incoherent power average prescribed by A4.
2. Hann-window sidelobes generated nearby local maxima that poisoned module
   indexing. Added strongest-first peak exclusion zones.
3. One small coefficient bound falsely promoted high-index periodic lattice
   peaks to a third generator. Split the bounds: a well-conditioned generator
   pair may carry large indices while extra module generators remain tightly
   bounded.
4. The initial expectation that the spectre peak set should be 12-fold was
   wrong. The literature target is chiral sixfold (with Friedel symmetry);
   both hat and spectre measure sixfold.
5. Render downsampling initially erased one-pixel Bragg peaks. Central
   k-space cropping plus max pooling preserves them.
