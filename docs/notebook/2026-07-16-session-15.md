## Exact recursion

At each level the solver enumerates every hole-free exact cover of the
current vertex ring. A negative depth-d result means no chain among all
earlier-corona choices reaches d. This is stronger than extending a convenient
stored witness and is necessary for exact Heesch depth.

The node budget is shared across the recursive search for one shape. Any
exhaustion remains in a separate survivor stream for targeted escalation.

## Performance lesson

Depth-3 positive extension can be fast: the first 100 n=16 and n=13 samples
all reach three coronas. Exact H_c=2 negatives can be far slower because all
earlier choices must be exhausted. The next implementation should:

1. extend stored depth-2 chains first to obtain cheap positive witnesses;
2. run exhaustive recursive fallback only where exact negative depth matters;
3. compare depth within each size class rather than treating raw depth as a
   size-independent score.
