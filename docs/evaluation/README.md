# Evaluation and postmortems

This directory owns assessments of research methods and completed campaigns.
An evaluation record is evidence about a method or process; it is not current
research authority and it is not automatically a reusable benchmark.

- [`postmortems/E1_CLASSIFIED_CORPUS_ASSESSMENT.md`](postmortems/E1_CLASSIFIED_CORPUS_ASSESSMENT.md)
  explains why the historical Hat--Turtle funnel is a valuable reproduction
  and component validation but not a sealed quantitative discovery benchmark.
- [`postmortems/RESEARCH_RETURN_AUDIT.md`](postmortems/RESEARCH_RETURN_AUDIT.md)
  records the go/no-go audit that stopped further return-free escalation.

A future benchmark belongs here only when its corpus, labels, protocol,
comparison methods, metrics, leakage analysis, and outcome interpretation are
sealed before evaluation. The repository currently has no such general
discovery benchmark.
