## Failures and corrections

1. Applying the immediate exact cover to 34,649 physical tiles initially hit
   Python's recursion limit after thousands of independent choices. The search
   was reformulated over disconnected overlap components; peak memory fell
   from about 1.4 GB in the failed run to about 150 MB for recursive recovery.
2. A fixed cyclotomic multiplication/inflation map was sought and rejected:
   no exact map carries one 496-node anchor set to the next. Inspection of the
   generator confirms why—the exact child translations are rebuilt from the
   previous supertile boundary and are level-dependent. D-0013 records
   scale-specific rule recovery instead.
3. Nearest-anchor mining exposes the first coarse 8/7 rule but not later
   scales once the sample shrinks. Exact graph transfer between consecutive
   patch sizes replaces that fragile proposal mechanism.
4. Unlabelled supertile interiors split into only two congruence classes, not
   nine. The nine supplied states are collar/context distinctions. Radius-1
   oriented collars recover a finite 17-state refinement instead of forcing an
   unjustified nine-way interior classification.
5. The true two-tile Gamma/Mystic motif is geometrically repeated elsewhere in
   the 9-tile scaffold, and candidate physical-node adjacency does not transfer
   unchanged to the first supertile scale. Bottom fusion remains open.
