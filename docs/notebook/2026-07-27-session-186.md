# Session 186 — all-singleton P17 subdivision theorem

## Experiment pre-registration

### Proposition

Enumerate every lozenge tiling (perfect matching of adjacent primitive
triangles) of the exact 34-triangle P17 support.  Decide whether every such
17-rhombus subdivision contains a physical vertex at which three rhombi of
the three distinct SAB axes meet and exhaust all six incident triangles.
Such a vertex forbids an all-singleton-M source interpretation because it
would require the three incident binary corridor-gap values to be pairwise
unequal.

If the geometric triple is not universal, build the exact binary inequality
graph induced by each surviving subdivision and decide its bipartiteness
instead; serialize the first satisfiable subdivision if one exists.

### Prior art and non-redundancy

Perfect-match enumeration of a finite lozenge region is standard dimer
theory.  The source-specific proposition is not published: P17 was derived
in sessions 178--185, and N60V initially used only its inherited subdivision.
The complete carrier-local impossibility theorem quantifies over every
source subdivision contained in the same unmarked support, so this check is
load-bearing rather than a search for another candidate.

### Outcome decisions

- If every subdivision contains the three-axis vertex (or otherwise has an
  unsatisfiable exact M-inequality graph), N60V is promoted from the inherited
  subdivision to all carrier-local all-M states.  Together with N60C and the
  area dichotomy this proves N60P for P17.
- If a subdivision has a satisfiable M-state graph, withdraw the universal
  N60V/N60P wording and retain that exact subdivision as the only admitted
  composition-cone escape.  Its complete source vertex/SAB extendability,
  not another polygon, becomes the next question.

### Stop rule and finite justification

Use only the fixed 34 primitive triangles of the first serialized P17
equalizer.  Enumerate every adjacency perfect matching exactly once by
canonical recursion; for each, inspect only its finitely many lattice
vertices and binary constraints.  No larger support, tiling radius,
periodicity index, polygon deformation, or solver budget is permitted.
