## Why the larger patch mattered

Learning each patch separately returned the same headline minimum—15
seven-parent patterns—but only 13 exact patterns overlapped. The original
15-pattern library recognized at least one local occurrence around every
training node in the doubled patch, yet its global exact-cover formula was
UNSAT. Conversely, the naive 17-pattern union covered the new patch but
introduced 199 optional occurrences. Neither outcome is a stable recursive
language.

The accepted calibration therefore minimizes one shared rule set subject to
both patches' exact-cover constraints.

## A4 patch-doubling regression

The first slow regression run classified the r²=100,000 hat patch as rank 5
instead of rank 4, although it remained sixfold and quasicrystalline. Reusing
the spectrum while sweeping indexer parameters localized the failure: the
strongest 100 peaks still indexed at rank 4, while a relation entering after
peak 120 required a free coefficient of magnitude 7 or 8. The previous
bounded search stopped at 6.

The calibrated free-generator bound is now 8 (the solved generator pair keeps
its separate bound 48). Both r²=50,000 and r²=100,000 patches recover rank 4
and symmetry 6, and the slow regression explicitly tests both stored
certificates. Raising this bound makes more integer relations available to
the local test; the existing wider E4 reference tests remain green.
