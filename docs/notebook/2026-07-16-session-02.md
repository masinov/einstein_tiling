# Session 02 — 2026-07-16 — Shape database + A1 periodicity rejection

## Done

1. **Shape database v0** (`src/einstein/db.py`, §7.4 minimal): SQLite at
   `data/shapes.sqlite`, shapes keyed by canonical form; verdicts carry
   certificate JSON, budget JSON, code version, timestamp. Batch jobs are
   resumable (existing verdicts are skipped).
2. **A1 torus test** (`src/einstein/funnel/a1_torus.py`): grid-aligned
   periodic tiling ⟺ exact cover of a quotient torus. Sweeps all
   center-sublattices in Hermite normal form up to index `k_max`; placements
   = 12 point ops × translation classes; exact cover by bitmask backtracking
   with min-branching heuristic and node budget. Positive results are
   machine-verified certificates (independent re-check in
   `verify_certificate`, tamper-tested). Budget exhaustion is a distinct
   verdict (`unknown-budget-exhausted`), never conflated with refutation.
3. **Batch run** over all 1,264 free polykites n ≤ 8 (k_max=12, node budget
   200k): ~40 s single core, zero budget exhaustions. Verdicts in
   `data/shapes.sqlite` (committed; 360 KB).

## Verified (evidence)

- **External anchor:** Joseph Myers' polykite tiling census
  (polyomino.org.uk/mathematics/polyform-tiling/, fetched this session;
  computations 2023). Myers' scope is identical to ours (he restricts to
  tilings aligned to one Laves grid). Derived expected periodic-capable
  counts: n=1..8 → 1, 1, 4, 5, 1, 71, 55, 39 (n=8: 37 isohedral + 2
  three-anisohedral; his third anisohedral entry is the hat, k=∞/aperiodic).
- **Our A1 batch reproduces all eight counts exactly.** Since positives are
  certificate-verified (no false positives), exact agreement also excludes
  false negatives at this budget. Regression test:
  `tests/test_a1_vs_myers.py` (n≤6 fast, n≤8 slow).
- **The hat survives A1** with `no-periodic-at-budget` (shape id 635) — it is
  proven aperiodic, so any certificate for it would have been a solver bug;
  also a fast regression test (`test_hat_gets_no_periodic_certificate`).
- A-priori concern that isohedral tilers might need torus index up to
  2n = 16 (12 tiles per translational domain): empirically k ≤ 12 sufficed
  for every periodic 8-kite — proven sufficient by the exact Myers agreement.
- 23 tests green (fast suite 2 s; slow suite 42 s).

## Observations for later stages

- A1 survivor sets (einstein candidates ∪ non-tilers) per n:
  0, 1, 0, 5, 26, 14, 207, 834. The hat hides among the 834 at n=8;
  separating candidates from non-tilers is exactly A2's job (Heesch depth).
- Myers also reports hole counts (28 holed 8-kites, all necessarily
  non-tilers at these sizes since a hole of area < n can't be filled);
  useful A2 shortcut: holed shapes can be pre-classified.
